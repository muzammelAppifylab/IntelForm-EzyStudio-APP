Blog posts live here: one Markdown file per post (my-post.md -> /blog/my-post/).

Front matter at the top of each file (checked at build by src/content.config.ts):
  title, description, publishedAt (required)
  author, cover + coverAlt, tags, updatedAt, draft: true (optional)

A new post goes live, with the blog list, RSS feed and sitemap, on the next Publish.
